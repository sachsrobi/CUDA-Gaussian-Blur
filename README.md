# CUDA Gaussian Blur – CPU vs. GPU

An university assignment project implementing a 3×3 Gaussian blur filter in C++ and CUDA, with a focus on comparing CPU and GPU performance.

### Features
- CPU-based Gaussian blur implementation
- CUDA GPU implementation using shared memory
- Execution time measurement and performance comparison
- Image boundary and corner handling

**Technologies:** C++, CUDA, Visual Studio

**Documentation:** Detailed Hungarian documentation is included in the repository, describing the algorithm, implementation, and performance evaluation.
